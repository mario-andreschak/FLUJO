# `src/vendor/avatar` is a byte-for-byte copy of flujo-avatar: change it there and resync

The files are generated by flujo-avatar's `npm run sync:flujo` and pinned by
their SHA-256 in `src/vendor/avatar/PROVENANCE.json`. A local edit drifts from
the published avatar SDK, so lint rules that the copy breaks are switched off
for exactly those files in `eslint.config.mjs` instead of being fixed in place.
That exception only holds while the copy matches its provenance.

Enforced by:
- `__tests__/architecture/vendorAvatarProvenance.test.ts`
