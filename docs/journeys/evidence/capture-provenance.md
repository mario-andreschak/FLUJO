# Screenshot provenance

The [capture manifest](capture-manifest.json) records all **18 public screenshots**, including UTC capture times, dimensions, SHA-256 hashes, captions and retake status. Every image was visually reviewed, its 1600 × 1000 PNG dimensions checked, and its repository hash matched to the virtual computer's original capture.

These are unmodified Gdk root-framebuffer captures of a real Debian/Xfce desktop running Chromium and FLUJO. The agent operated the software, reviewed memory suggestions and supplied the demonstration's approval steps. This is an operator-reviewed demonstration, not an independent human usability study. No UI was composited, generated, cropped or edited into the images. No credential values were visible in the reviewed public PNGs.

The runtime is the published **`flujo-ai@3.46.2`** package. The documentation source tree is version 3.46.3; it was not the captured runtime. **Workshop AI** uses OpenRouter's `google/gemini-3-flash-preview`. The connected app was cloned from `https://github.com/zcaceres/fetch-mcp`, and Coffee workshop helper received all six of that app's tools.

“Day 1”, “Day 2” and “Day 3” are **three compressed demonstration sessions on October 11, 2026**. They do not represent three elapsed days or unattended reliability. The operator paused and resumed the ongoing goal, reviewed suggested memory and supplied final approval. The goal controller completed after four work sessions. Invitations remained drafts; no invitations were sent and no purchases were made.

The initial package installation happened before the main recording. `01-installed-home.png` shows the original running home page; it is not installation-command evidence. A **separately recorded genuine second installation** ran `npm install --prefix /workspace/install-take flujo-ai@3.46.2` into a previously absent prefix, with existing Node/npm tooling and npm download cache. The measured install took **55,335 ms**; npm reported **551 packages in 55 seconds**. This excludes initial machine setup and is not a first-install time estimate. An initial launch on port 4201 encountered `EADDRINUSE`; the fresh-data instance then started on port 4300 and returned HTTP 200. `00-install-receipt.png` re-displays the actual npm log, `npm ls` result and ready URL after completion. `00b-clean-install-home.png` shows that second instance's fresh home page.

The first helper response used a 5,000-character source extract that omitted the brewing steps and led to an incorrect ratio. `07-verified-checklist.png` shows the corrected answer after a follow-up requested `fetch_readable` with `max_length: 20000`. It is not evidence of a correct first reply. `05-agent-app.png` shows the app binding, not a restriction to only `fetch_readable`.

`04b-mcp-run-config.png` is a later view of the saved server configuration; its edit dialog was canceled. `09-day1-goal.png` is a later retake of the original fully filled goal form after the real goal completed; it was canceled without creating a duplicate goal. `12-day2-shopping.png` and `14-day3-runsheet.png` are later captures of persisted real chat output, not new responses. The Day 2 shopping list is intermediate: the final reviewed pack makes its fourth lead equipment set optional and specifies 24 cups.

`10-day1-memory.png` shows the invitation already remembered while the workshop-plan suggestion still needs review. `15-day3-approval.png` shows operator-corrected final details marked Important. `16-day3-goal-completed.png` records the actual completed-goal badge and four work sessions. Its original description still says six adults and its stale Next step still asks for final approval, while the completion summary records eight adults and fulfilled approval. This wording is preserved in the image.

Two raw recordings remain private local evidence and are not committed: `first-use-recording.mp4` (**1,908.9 seconds**) and `clean-install-take.mp4` (**260.7 seconds**). Their sizes and independently checked SHA-256 hashes appear in the manifest. The main recording excludes the initial installation; the second contains the supplemental installation take. This manifest does not claim a full-frame privacy review of those raw recordings.

AI-test timings describe that one run. Provider charges are not established by the screenshots; a zero cost field must not be interpreted as free usage.
