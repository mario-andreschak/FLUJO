Prepared Source only. No result is claimed until this exact Source is built,
executed, and frozen receipts are retained. Run in a coordinated CPU window,
using a fresh output folder outside the checkout. Do not alter Source while

Run `fixtures.py OUTPUT`, then `node build.cjs REPOSITORY OUTPUT`, then
`python supervise.py REPOSITORY OUTPUT`. The Windows supervisor uses the
existing local Node runtime; set the browser executable with
`FLUJO_PROFILE_CHROMIUM` if the existing local installation differs. No
installation, provider call, production conversation, or external request is
part of this profile.

The browser mounts the actual Chat root, actual providers and children, and
actual frontend services. Next framework router contexts are supplied by the
harness. Selection through the real timeline exercises root effects; no
snapshot is injected into React state. Synthetic completed state and timeline
are persisted in a disposable workspace. Workspace readiness, encryption,
owner policy/session, guarded routes, admission and cancellation execute
actual Source. This is a transpiled Source harness, not packaged application
startup or provider endurance qualification.

All six generated archives are exactly 64 MiB. Each includes a substantial
Unicode canonical history; their remaining SDK payloads exercise ASCII,
Unicode, escapes, dense objects, wide objects and deep nesting. Complete
logical-byte hashes are generated independently. No reduced size ceiling or
truncated persisted history is used. Historical branches are selected for
the first five boundaries; the final boundary also checks the Live cursor
through the actual root.

Four actual authenticated HTTP responses are paused at headers, retaining
real descriptors and admissions. A fifth request must return 429. One client
disconnects; the remaining three are drained with bounded records and checked
against complete byte counts and hashes. A separate controlled fault wraps
only the next actual archive descriptor close: three immediate close attempts
fail, admission remains quarantined, and the original descriptor must close
during the bounded production retry. This injected failure is a cleanup
qualification seam; it is not represented as a naturally occurring OS fault.

heap 384 MiB and backend RSS 512 MiB; no forced GC. Expanded complete profile
deadline is 180 seconds. Browser aggregate RSS is reported separately.

and do not increase deadlines or caps to obtain acceptance.
