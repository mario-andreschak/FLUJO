# FLUJO pilot: weekly form

About five minutes, once a week. Copy the questions into an email reply, or the
pilot owner can turn them into an online form. Answer with your **tester
number**, not your name.

Please do not paste keys, prompts, conversations, file names, web addresses or
screenshots of private work.

---

**Tester number:** p____  **Week:** ____ (1 to 8)

**FLUJO version** (Settings → Updates, or the first lines of the diagnostic
report): ________

### This week

1. Did you use FLUJO for your own work this week?
   - [ ] Yes
   - [ ] No. Main reason (optional): ________

2. How many real tasks did FLUJO **finish** the way you wanted? ____

3. How many real tasks **failed**, or did you give up on? ____

4. Did a finished task use a connected app (MCP server)?
   - [ ] Yes  - [ ] No  - [ ] Not sure

5. In one line, what was the task? Describe the kind of work only, for example
   "sort new GitHub issues" or "check release notes against the version file".
   ________

6. Did it help? Pick the closest one.
   - [ ] It saved me time
   - [ ] It gave me more control or let me catch mistakes
   - [ ] It let me reuse one app setup in several programs
   - [ ] No real benefit
   - [ ] I can't tell yet

7. How many times did you need help from someone (the pilot owner, a friend,
   a forum) to get something working? ____

### Problems

8. Did something go wrong? Tick all that apply.
   - [ ] Installing or starting FLUJO
   - [ ] Something missing on my computer (Node.js, Python, Docker, …)
   - [ ] Signing in to the AI or an app
   - [ ] AI quota, credit or cost limit
   - [ ] An app's tools did not show up
   - [ ] A tool's form was confusing or lost what I typed
   - [ ] A tool call failed
   - [ ] The agent used the wrong AI or app
   - [ ] FLUJO crashed, hung or got slow
   - [ ] Approving or rejecting a tool call
   - [ ] The debugger
   - [ ] Using a FLUJO app from another program
   - [ ] Hard to use with keyboard, screen reader or zoom
   - [ ] I didn't know what to do next
   - [ ] Something else

9. For the worst problem: what did you do, what did you expect, and what
   happened? ________

10. Did it stop you from finishing the task?
    - [ ] Yes  - [ ] No, I found a way around it

### Optional

11. Diagnostic report (Settings → Privacy & usage → Diagnostic report → Copy).
    Paste it here only if you read it and are happy to share it.

    ```
    (paste here)
    ```

12. Anything else you want to tell us? ________

13. Do you want to keep going next week?
    - [ ] Yes  - [ ] No, please stop my reminders

---

For the pilot owner: question 8 maps to these problem codes, in order:
`installation`, `prerequisite`, `authentication`, `quota`, `discovery`,
`tool-form`, `tool-call`, `model-binding`, `runtime`, `approval`, `debugger`,
`proxy`, `accessibility`, `unclear-next-step`, `other`. Question 6 maps to
`time-saved`, `better-control`, `connection-reuse`, `none`, `unmeasured`.
Copy the answers into the [tracking sheet](tracking-sheet.csv) as described in
[start here](start-here.md#fill-in-the-sheets). Keep question 5, 9 and 12
answers in your private folder; they do not go into the sheet.
