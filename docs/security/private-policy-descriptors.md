# Stable private owner and MCP approval reads

The synchronous readers in owner authorization and managed MCP approval used `openSync(..., 'r')`, numeric metadata and no file/name checks after reading. A regular policy replaced by a FIFO between admission and open could block the server thread. A same-size inode replacement or mutation during a read could return policy bytes without establishing one unchanged file. These seams are used for initial admission, durable owner witnesses, container launch/start and final managed dispatch.

Both readers now use a shared synchronous policy reader. Its one descriptor opens with `O_RDONLY | O_NOFOLLOW | O_NONBLOCK` where available. Requested name, canonical name and opened descriptor are bound through exact bigint device/inode/size/nanosecond timestamps/mode/uid/gid/link-count comparisons before and after the bounded read. Leaf links and special files are denied. Allocation and reads stop at the admitted size plus one, capped at 64 KiB. The descriptor closes on success and all admitted failures before policy can escape.

Private admission runs before allocation or bytes: exactly one link, private POSIX permissions and the running POSIX UID where available. JSON requires valid UTF-8. Windows ACL privacy/ownership remains operator responsibility; no ACL qualification is claimed. This strengthens hardlink/ownership admission and deliberately rejects a file owned by another POSIX UID. Operator policy paths must remain trusted; this patch does not authenticate ancestor-directory ownership or add an outside-DataRoot placement contract.

Owner responses continue to project fixed `OWNER_AUTH_UNAVAILABLE` / 503. MCP reads project fixed `ISOLATION_UNAVAILABLE` and retain existing no-host-fallback and managed-generation close behavior. Existing expiry, owner/workspace matching, policy digest and revocation checks remain in force. The reader does not create a transaction spanning the separate owner/approval files, keep a stream continuously revoked, change isolation defaults, or isolate installation commands.
