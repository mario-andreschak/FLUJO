# Undici dependency security patch — October 16, 2026

The daily review found new [Undici 8.12.2 security fixes](https://github.com/nodejs/undici/releases/tag/v8.12.2), also released as [7.30.1](https://github.com/nodejs/undici/releases/tag/v7.30.1). The [TLS renegotiation advisory](https://github.com/nodejs/undici/security/advisories/GHSA-qrxm-fqhp-jwvm) identifies affected 8.x versions below 8.12.2 and 7.x versions below 7.30.1. FLUJO had both: root 8.11.2 and MCP proxy 7.30.0. This patch updates those two lock records and the root dependency minimum. No other package record changes. Existing Node support and the MCP proxy's compatible 7.x range remain intact.

The vendor release covers TLS renegotiation crashes, lost TLS verification callbacks, redirect/cache isolation, excessive content encodings, decompression-handler errors, integrity algorithm casing, EventSource parser bounds and WebSocket PONG backpressure. Repository alert ingestion has not yet listed these new advisories; the global advisory API returns404, while the vendor's public repository advisory pages establish the release ranges.

After patch, six security cases and six actual production OpenAI transport cases pass. The excessive-encoding subprocess controls pass before and after; this is not an exploit reproduction of every listed advisory.
