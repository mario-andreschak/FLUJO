# Node security runtime floor - October 21, 2026

## Immediate FLUJO fix

[Node's October 21 advisory](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases) affects our previous Node 22.23.3 runtime. CVE-2026-111497 concerns a Brotli decoder out-of-bounds write permitting RCE. The release also fixes DNS NUL truncation, TLS hostname validation, response reuse, snapshot entropy and permission-model problems, and updates bundled dependencies and CA trust. A separate npm Undici update cannot patch Node's built-in fetch/decompression/TLS implementation.

This patch requires **22.23.4 or later within 22.x, or 24.22.1 or later within 24.x**. It updates all six first-party engines and lock entries, application/MCP preflight, both installers, updater fixtures, active build/release/installer workflow pins, both Docker stages and the official-binary manifest. Node 26 remains outside the application's supported majors. The minimum/current profiles coincide; each distinct release runtime retains actual packed-process qualification in release CI without duplicate runs.

The official checksum signatures were verified with the repository's previously pinned Node release keyring. Windows executables and ZIPs matched signed hashes; Linux executable and libuv-header hashes were derived from signed archive bytes without executing them. The ECR mirror independently reported the same image index digest as Docker Hub: `sha256:de170b39439eb0e5a3444ad7d60b015614a381e10fecae2e30ec9e735122f38d`. The [signed receipt](evidence/node-security-2026-10-21/verified-node-binary-receipt.json) retains the derivation. This is registry/binary verification, not a container build or release acceptance result.

The immutable 8fe payload-export workflow is already inert under its event/ancestry conditions. Its setup pin is patched, but its historical source verifier will refuse the new runtime if the workflow is activated. That export needs separate requalification; original source/hash assertions are preserved.

## Validation

The patch is based on main b9591085fc0633fe231c3410c2d195ccfbdb7cb7, which already
includes Next 16.4.2, follow-redirects 1.16.1 and Hono 4.13.13. Local application
typecheck, source/changed-script lint and installer syntax checks pass on Node
22.23.4. The non-container application build passes in 371.178 seconds. Full CI, container builds,
release suites and publication are deferred to combined release pre-flight.
No external model/provider calls were made.

The separate workstation and adjacent-project CVE inventory is retained in the
local security handover, rather than included in the distributable package audit.
A source patch does not update already running applications or published images.
